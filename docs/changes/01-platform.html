01这个模块负责什么#

它不是一个业务服务，而是所有服务共同站着的地面。本地依赖、构建入口、流水线和跨服务的公共代码都在这里。

本地依赖 deploy/

compose 起 MySQL、Redis、Kafka，端口写死在 127.0.0.1。业务库由 make db-init 执行 init.sql。

统一入口 Makefile

起停依赖、生成代码、单测、数据层测试、灌数据、端到端都有对应目标。

流水线 ci.yaml

push 与 PR 触发四个并行任务，覆盖契约、Go 单测、MySQL 数据层与两个前端。

公共包 pkg/

各服务共用的鉴权、密钥检查、追踪、测试建库和 Kafka 发件箱。

03实现逻辑#

服务启动顺序

七个服务和 gateway 的 main.go 走同一条启动链。密钥检查放在装配之前，不合格就不会监听端口。

  1. trace.Setup()装全局追踪，退出时 Shutdown
  2. config.New只接 file.NewSource
  3. c.Scan(&bc)扫进手写 conf 结构体
  4. secretcheck.Check不合格 os.Exit(1)
  5. wireAppWire 装配各层
  6. app.Run()阻塞到收到停止信号

HTTP 端口自验令牌

各服务的 HTTP 端口可以被直接访问，所以不能相信请求里自带的身份头。httpauth.Server 挂在 metadata.Server() 之后，先清掉身份键，再按规则写回验签得到的身份。

pkg/httpauth服务端口的身份闸门
入口
httpauth.Server(Options)，返回 Kratos 中间件
选项
UserSecret、AdminSecret、Public、Optional（后两者是 operation 名单）
后台判定
看 URL 路径是否以 /v1/admin/ 开头，不看 operation
角色规则
AllowAdmin(path, role)，gateway 的 allowAdmin 直接调用它，两边共用一套
验签函数
VerifyUser / VerifyAdmin，gateway 的两个验签器也是它们的薄包装
测试辅助
httpauthtest.RejectsForged：只带伪造身份头直连，必须得到 401

配置只读文件

地址和令牌密钥直接写在 dev.yaml 与 prod.yaml。不再用占位符，也不再接环境源。

之前env.NewSource("KRATOS")

设置 ADMIN_JWT_SECRET=x 后读到的仍是 change-me-… 缺省值。

由 TestPrefixedEnvMissesPlaceholder 固定这个反例。

现在只读 yaml

地址和密钥写在 dev.yaml / prod.yaml，不再从环境变量替换。

由各服务的 conf 测试按文件里的字面值核对。

其余三个公共包

secretcheck

Check(keys...) 逐把检查：空白或与前面某把相同就记错，全部用 errors.Join 一次报出；仍以 change-me- 开头只打警告。

trace

Setup() 设全局 sdktrace.TracerProvider 与 propagation.TraceContext，日志通过 tracing.TraceAttrs 带上同一个 trace id。

testdb

Open(t, name, models...) 先 DROP 再 CREATE 独立库并 AutoMigrate，不碰服务正在用的库；连接串是 root:root@tcp(127.0.0.1:3306)/。

ipkg/kafkaout 在订单、支付、通知文档里展开

它提供 Insert（事务内写发件箱）、StartPublisher（每秒投递一批）和 StartConsumer（同一条原地重试，200ms 起翻倍封顶 3s，连续失败 5 次跳过）。

05关键规则与失败处理#

httpauth 判定表

请求情况结果错误
operation 在 Public放行，不写身份—
后台路径，无令牌或密钥不对拒绝，买家令牌验签即失败401 UNAUTHORIZED
后台令牌 aud 不含 admin 或缺 role拒绝401 UNAUTHORIZED
后台令牌有效，角色不符拒绝403 FORBIDDEN
买家路径，令牌有效写 x-md-global-user-id—
买家路径，令牌无效，在 Optional放行，不写身份—
买家路径，令牌无效，不在 Optional拒绝401 UNAUTHORIZED
算法不是 HS256 / 密钥为空parseHS256 直接拒401 UNAUTHORIZED
传输不是 HTTP中间件不处理—
