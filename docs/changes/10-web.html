01这个模块负责什么#

web 是买家用的 H5 商店。它不直连任何业务服务，开发时 Vite 在 5174 端口把 /v1 代理到 127.0.0.1:8080 的 gateway。

apiapi/

12 个文件：10 个业务模块 + client.ts（统一 send）+ read.ts（宽松读字段）。

会session/

令牌与用户号的存取、sameOriginPath / safeFrom 回跳校验。

页pages/

16 个页面组件，每页自己管加载、提示和错误文案。

件components/

Goods.tsx 商品卡与翻页条，usePager 用栈记住走过的 page_token。

¥format/

price.ts 金额、html.ts 图文清洗、specs.ts 规格与库存文案。

05关键规则#

详情页能不能买

条件主按钮文案可点
商品 status = 6 已下架已下架禁用
status ≠ 5 在售暂不可售禁用
所选 SKU 可用库存 ≤ 0缺货禁用
所选 SKU 未启用加入购物车禁用
其余加入购物车 · 立即购买可用

有货

可用库存大于 10

仅剩 N 件

可用库存 1 到 10

缺货

可用库存 ≤ 0，还没查到时不显示

订单状态与动作

status文案买家能做
1待支付去支付 · 取消，详情页显示支付截止
2已支付无操作，等运营发货
3已发货确认收货
4已完成逐项评价，已评价显示标签
5已取消只能查看

金额与图文

规则做法
formatPrice分先 trunc，元 = floor(|分|/100)，分补两位，全程整数
价格区间输入按元填，^\d+(\.\d{1,2})?$，不合法提示
标签白名单保留 42 种排版标签，其余拆壳留文字
整块丢弃script、iframe、form、svg、style 等 20 种
属性只留 alt、title、宽高、合并格、align
链接与图片只放 http / https / 相对地址，链接另放 mailto
外链强制 target=_blank 与 noopener noreferrer nofollow

07已知遗留#

环境randomUUID 需安全上下文

crypto.randomUUID 只在 HTTPS 或 localhost 可用。用局域网 IP 走 http 打开时，点「提交订单」直接抛错。

幂等重试复用旧请求号

订单建成但支付单失败后，改勾选再提交，URL 没变就沿用旧号。order 按号返回已有订单，新勾选不生效。

分页订单列表只拉第一页

listOrders() 不带 page_token，服务端默认 20 条。更早的订单在列表里看不到。
