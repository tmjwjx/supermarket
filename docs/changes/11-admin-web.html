管理台 frontend/admin-web

React 19 · react-router-dom 7 · Vite 8，运营同学的后台

一个前端管完商品、目录、推荐位、库存、订单、对账和运营账号：令牌用独立的 admin_access_token，所有请求走 /v1/admin/*；商品编辑是四步表单，在售时锁住规格结构只放行改价和文字。

01这个模块负责什么#

admin-web 只请求 gateway，开发时 Vite 在 5173 端口把 /v1 代理到 127.0.0.1:8080。页面按运营角色分成三块，后端按路径前缀判角色。

商商品生命周期

商品列表、四步编辑、审核、回收站、操作日志。

目目录与运营位

属性模板、两级分类、品牌、推荐位、库存入库出库。

单交易

订单列表与发货、按单号发货、支付对账差异。

号运营账号

建号、改角色、停用启用、重置密码，只给超级管理员。

06验证与测试#

07已知遗留#

并发在售保存可能回滚别人的改价

PUT 里每个 SKU 带的是打开页面时的 origPrice。这期间别人改过价，保存会把价格写回旧值。

分页全量列表 page_size 超上限

listAllProducts 每页要 100，后端 paging.Size 静默收成 50。最多翻 20 页，超过 1000 件拿不到。

!
分页上限影响不止商品页

审核、库存、推荐位的商品下拉也都调 listAllProducts；回收站的 listDeleted 同样传 100，但它有「加载更多」，只是每页实际 50 条。
