01这个模块负责什么#

admin-web 的登录和运营账号管理都落在这个服务。它签发的后台令牌被 gateway 和五个业务服务共同认可。

super 超级管理员

后台全部路径，唯一能管理运营账号的角色。

  • /v1/admin/users…
  • 订单、支付与全部商品后台

product 商品运营

商品目录与库存后台。

  • /v1/admin/products…、品牌、类目
  • 推荐、属性模板、/v1/admin/stocks

order 订单客服

订单与支付后台。

  • /v1/admin/orders…
  • /v1/admin/payments…

三种角色都能调 /v1/admin/me 查看自己。

03实现逻辑#

登录

登录是 admin 唯一的公开接口。四个检查点依次执行，任何一步不过就返回，不会签发令牌。

issueToken后台令牌
算法
HS256，密钥 auth.jwt_secret，开发配置写死为 tmjwjx-admin-jwt-secret
sub
运营账号 id（UUID）
aud
["admin"]；VerifyAdmin 要求 aud 含 admin，否则 401
role
自定义声明，值是账号当前角色
有效期
token_expire_ms: 43200000，即 12 小时；配置不大于 0 时也按 12 小时
返回
expires_in_ms 与有效期一致，前端据此安排重新登录

账号管理

四个管理接口在 service 层先过 requireSuper，再交给用例。用例只做参数校验，账号是否存在、用户名是否冲突由数据层映射成类型错误。

Create建号
用户名
去空白后非空，不超过 64 字节；唯一索引冲突（MySQL 1062）返回 ADMIN_USERNAME_EXISTS
显示名
为空时取用户名，不超过 64 字节
角色
必须是 super、product、order 之一
口令
非空即可，bcrypt DefaultCost 哈希后存 password_hash
初始状态
固定 status = 1 启用；id 用 UUID v7
Update · Reset改角色、停用、重置口令
部分更新
空 role 与 status=0 表示不改；两者都没给返回 400
合法值
role 限三种；status 只能是 0、1、2
目标不存在
更新影响 0 行时返回 ADMIN_NOT_FOUND
重置口令
口令非空，重新 bcrypt 后只更新 password_hash
列表
按 created_at 升序返回全部账号，不分页

初始超级管理员

种子命令不经过 CreateAdminUser 接口，而是直接装配用例，所以不需要令牌。用户名固定为 admin，角色固定为 super。

  1. make seed-admin读 admin 的 dev.yaml
  2. initPassword读 seed.init_password，去空白，至少 8 个字符，空则退出
  3. 读配置只读 yaml 文件
  4. data.NewData连库，按配置 AutoMigrate
  5. uc.Seed("admin")已存在跳过，否则建 super

05关键规则与失败处理#

登录判定

情况结果错误
用户名去空白后为空，或口令为空拒绝400 ADMIN_INVALID_ARGUMENT
用户名不存在拒绝401 ADMIN_INVALID_CREDENTIALS
账号已停用（不论口令）拒绝403 ADMIN_DISABLED
口令不匹配拒绝401 ADMIN_INVALID_CREDENTIALS
全部通过签发 12 小时令牌—

管理接口判定

情况结果错误
缺 admin-id 或 role，或 id 不是 UUID拒绝401 ADMIN_INVALID_CREDENTIALS
role 不是 super拒绝403 ADMIN_FORBIDDEN
建号参数不合法拒绝400 ADMIN_INVALID_ARGUMENT
口令超过 72 字节bcrypt 报错，映射为参数错400 ADMIN_INVALID_ARGUMENT
用户名已存在拒绝409 ADMIN_USERNAME_EXISTS
改账号时 role 与 status 都没给拒绝400 ADMIN_INVALID_ARGUMENT
目标账号不存在拒绝404 ADMIN_NOT_FOUND

种子判定

seed.init_password结果
未写入或只有空白exit 1 seed.init_password is required
去空白后不足 8 个字符exit 1 must be at least 8 characters
合格，但 admin 已存在跳过 日志 admin seed skipped
合格且 admin 不存在新建 super 日志 admin seed created
i停用只拦登录，不吊销已签发的令牌

gateway 与各服务验后台令牌时只看签名、aud 和 role，不回查账号状态。停用或改角色后，旧令牌在 12 小时有效期内仍按旧角色生效。

07已知遗留#

!先判停用再验口令，可以探测账号是否停用

对已停用账号，用任意口令登录都返回 403 ADMIN_DISABLED，而不是 401。不知道口令也能分辨出“这个用户名存在且已停用”。

!超级管理员可以停用最后一个超级管理员

UpdateAdminUser 不检查剩余 super 数量，也不阻止停用自己或把自己改成其他角色。种子命令发现 admin 已存在就跳过，不会把它恢复成启用的 super。
