用户端 · 网关

进店只认网关

注册、登录、看自己的资料，都从用户端打到网关。页面只管表单和展示。令牌怎么签发、用户存在哪，留在 user。

三条路径都能单独打开，/ 直接进登录。浏览器只请求 /v1，开发时转到 127.0.0.1:8080。注册和登录公开并原样转发。查用户先在网关做 HS256 验签，失败回 401，请求不到 user。

3条用户路径根路径进入登录
8080唯一对外 HTTP不另开服务端口
401验签失败即停不把查询打到 user

02 只打网关 #

用户端不知道 user 的地址。开发服务器把 /v1 转到本机网关。

  1. 页面只发相对路径
  2. /v1代理到 8080
  3. 网关公开或先验签
动作请求门禁去向
注册 POST /v1/users/register 公开 原样转发
登录 POST /v1/users/login 公开 原样转发
查资料 GET /v1/users/{id} Bearer 先验签再转发
不要写 user 的端口

页面和请求层都不出现 8000 或 9000。9000 只存在于网关到 user 的 gRPC。

03 当次会话 #

登录成功后记下两样东西。页面展示资料时读出来，退出时一起清掉。

项规则
位置sessionStorage，限当次标签页
令牌键名 access_token
用户另存用户 id，键名 user_id
解析不读 JWT 载荷
续期不刷新令牌
退出两个键一起删除
查资料时怎么带

请求头是 Authorization: Bearer 加上已保存的令牌。用户 id 来自会话，不从令牌里拆。
